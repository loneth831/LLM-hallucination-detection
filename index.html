Multi-Signal Verification Architecture

Why traditional single-metric similarity fails, and how our multi-layer pipeline solves it.

🧩

Claim Decomposition

Splits multi-sentence LLM responses into atomic propositional claims to prevent factual errors from hiding inside otherwise accurate paragraphs.

🏷️

Entity & Number Auditing

Extracts proper nouns, years, percentages, and metrics. Flags high-risk fabricated entities like swapped locations or dates not present in source context.

⚡

Dense Semantic Embeddings

Utilizes MiniLM-L6-v2 vector embeddings to capture deep contextual meaning in under 15ms per claim, bypassing slow token-by-token comparison.

🚀

Production REST API

FastAPI backend with /v1/verify and /v1/verify/batch endpoints, OpenAPI documentation, and structured Pydantic schemas.

🎨

Visual Gradio UI

A full-featured interactive desktop dashboard with live sensitivity sliders, color-coded badges, and JSON payload inspection.

Benchmarking Suite

Integrated evaluation framework measuring Precision, Recall, F1, Latency, and Confusion Matrices on 10,000 paired QA datasets.
